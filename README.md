# dsmr5

[![Go Reference](https://pkg.go.dev/badge/mko.re/go/dsmr5.svg)](https://pkg.go.dev/mko.re/go/dsmr5)

A Go implementation of the [Dutch Smart Meter Requirements](https://www.netbeheernederland.nl/publicatie/dsmr-502-p1-companion-standard) 
standard, used in Belgian and Dutch smart meters.

Can for example be used with a [USB P1 Cable](https://webshop.cedel.nl/nl/Slimme-meter-kabel-P1-naar-USB), or with 
the [HomeWizard P1 Meter](https://www.homewizard.com/shop/wi-fi-p1-meter/)'s local API. See the [examples](https://pkg.go.dev/mko.re/go/dsmr5#pkg-examples) 
for more information.

This isn't a full implementation of the standard, but it covers whatever I need for my home automation / monitoring tasks.
